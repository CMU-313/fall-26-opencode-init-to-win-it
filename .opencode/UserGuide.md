## **Opencode TA Mode User Guide**

**TA Mode** is a flag added to OpenCode that automatically constructs and selects a “TA” agent with read-only permission and non-revealing answer responses. It is distinct from the other flags in OpenCode (such as when doing *opencode agent create*) as it **also provides the ability to export conversation usage data to a teacher or professor trying to learn more about the students’ AI usage.**
