Record one student performance note and compare it to classmates on the same assignment.

Call this after the student asks a question and gives their own solution. Pass the assignment name, a stable student name, how many questions they have asked, an attempt quality from 1 to 5, and the ideas they are stuck on. The tool saves the note in the shared class file and returns how this student differs from the class average. Report that summary. Do not invent the averages.
